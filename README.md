# Visor Arc

**Área:** Computação vestível e interfaces · **Status:** protótipo físico planejado.

Visor Arc é o projeto de um **HUD vestível** para mostrar informações contextuais e telemetria em uma interface compacta.

## Objetivo

Investigar uma interface de visualização próxima ao olho, com baixo consumo, conforto e leitura possível em condições reais. Uma interface visual no computador poderá servir como protótipo antes da montagem física.

## Primeiros marcos pretendidos

- Definir o conjunto mínimo de informações exibidas.
- Pesquisar display, componentes ópticos, alimentação e limitações de foco.
- Criar uma interface simulada e testar legibilidade.
- Montar um protótipo seguro com hardware compatível.

## Limites

Uma lente transparente simples não projeta imagens nítidas. Exibição óptica real exige componentes adequados, ergonomia e avaliação de segurança. Integração com a LUMI é possibilidade futura, não pré-requisito.

> Não existe visor físico funcional neste repositório neste momento.
