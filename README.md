Explore uma bancada de telemetria simulada com parâmetros, pausa, gráfico e exportação CSV. A interface funciona; o hardware físico e a visão computacional ainda não estão integrados.

## Executar

```sh
python -m http.server 8000
```

Abra http://localhost:8000/preview/. Nenhuma dependência npm necessária.

Nome oficial: **VYSION**. O endereço legado `Visor-Arc` é mantido até a renomeação administrativa do repositório.
